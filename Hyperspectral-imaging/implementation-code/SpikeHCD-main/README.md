# SpikeHCD: Spiking Transformer for Hyperspectral Change Detection

This repository contains the implementation of **SpikeHCD**, a Spiking Neural Network (SNN) based Transformer for hyperspectral image change detection. It features Parallel Spiking Neurons (PPSN), Memory-Enhanced Attention (MSA), and a Spiking Difference Module (SDM).

## Requirements
Install dependencies:
```bash
pip install -r requirements.txt

# Usage
Run the training script:
```bash
python run_spikehcd.py --data_path ./data --epochs 15
